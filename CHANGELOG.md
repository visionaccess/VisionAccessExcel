# Changelog

## 1.0.2
- Row cell list moved to Control+Shift+R, column cell list to Control+Shift+C and Sheet Manager to Control+Shift+S. The earlier NVDA+Alt+Shift keys clashed with the Windows input-language switch (Alt+Shift).
- No NVDA default commands are overridden.

## 1.0.1
- Stopped overriding NVDA's default NVDA+Shift+R, NVDA+Shift+C and NVDA+Shift+S commands.

## 1.0.0
- First release: "blank" announcement after deleting cell content, cell lists for the sheet, row and column with Enter to jump, Sheet Manager, table range in the Create Table and Resize Table dialogs, table information, used range and selection summary commands, settings panel.
