VisionAccess Excel Enhancements

Version 1.0.2. Author: Mukesh Jain, VisionAccess. Email: info@visionaccess.org. Website: www.visionaccess.org.

This NVDA add-on makes Microsoft Excel faster and easier to use with a screen reader. All commands work only inside Excel. If you are editing a cell, press Escape before using the list and sheet commands.

Keyboard commands

CommandWhat it does
Control+Shift+DLists every cell with data in the current worksheet. Each entry gives the cell address, its value, and says "formula" if the cell contains a formula. Press Enter on a cell to move to it.
Control+Shift+RLists the cells with data in the current row, with their column headers. Press Enter to move to a cell.
Control+Shift+CLists the cells with data in the current column, with their row headers. Press Enter to move to a cell.
Control+Shift+SOpens the Sheet Manager.
NVDA+Alt+TReports the name and range of the table at the current cell. In the Create Table or Resize Table dialog, reports the table range again.
NVDA+Alt+UReports the used range of the sheet: where the data starts and ends, and how many rows and columns it covers.
NVDA+Alt+SReports a summary of the selection: address, number of cells, cells with data, and for numbers the sum, average, minimum and maximum.

None of NVDA's default commands are changed: NVDA+Shift+R and NVDA+Shift+C still set row and column headers, and NVDA+Shift+S still toggles sleep mode. You can change any of these keys in NVDA menu, Preferences, Input gestures, category "VisionAccess Excel".

Cell lists

The cell list dialog has a Filter field, the list of cells, a "Go to cell" button and a Close button. Focus starts on the list. Type in the Filter field (Alt+F) to show only cells whose address or value contains that text. Press Enter on a cell to close the dialog and land on that cell in Excel. Press Escape to close without moving.

Sheet Manager

The Sheet Manager lists all sheets in the workbook with their position and whether they are active, protected or hidden. Select a sheet and use:

  • Go to sheet (Enter): activates the sheet.
  • Rename (Alt+R): gives the sheet a new name.
  • Move up (Alt+U) and Move down (Alt+D): change the sheet's position.
  • Protect / Unprotect (Alt+P): protects the sheet with an optional password, or removes protection.
  • Hide / Unhide (Alt+H): hides or shows the sheet.
  • Insert new sheet (Alt+I): adds a sheet with an optional name.
  • Delete (Alt+L): permanently deletes the sheet after you confirm.

Blank announcement

When you press Delete on a cell and the cell becomes empty, NVDA says "blank". When you are typing in a cell, the formula bar or any edit field in Excel and you delete the last character with Backspace or Delete, NVDA says "blank". You can also turn on "Announce blank when moving to an empty cell" in the settings.

Table range in dialogs

When you open the Create Table dialog (Control+T) or the Resize Table dialog (Table Design, Resize Table), NVDA announces the range of cells the table covers, for example "Table range: A1:D20". Press NVDA+Alt+T to hear it again.

Settings

Open NVDA menu, Preferences, Settings, and choose "VisionAccess Excel". You can turn each announcement on or off, show or hide headers in the cell lists, and set the maximum number of cells listed (default 2000).

Requirements

NVDA 2023.1 or later and Microsoft Excel 2013 or later (including Microsoft 365).
